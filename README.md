# GoLuckyTen

Сайт розыгрышей призов на **Laravel 13 + Inertia.js (v3) + React 19 + Tailwind CSS 4**.
Играть можно за деньги (покупка билетов) или бесплатно — через заявку на бесплатное участие (No purchase necessary), правила описаны в Terms & Conditions, раздел 6.

## Быстрый старт

Нужны PHP 8.3+, Composer, Node 20+.

```bash
composer setup        # composer install, .env, ключ, SQLite, миграции + демо-данные, storage:link, npm install, npm run build
php artisan serve     # http://localhost:8000
```

Для разработки с hot-reload: `npm run dev` в одном терминале и `php artisan serve` в другом.

Демо-данные: Porsche 911, Rolex Submariner, Range Rover Sport, AP Royal Oak, Mercedes-AMG G 63, Apple-набор, Cartier, €50,000 Instant Win Cash и другие, плюс уже сыгранные instant wins и победители.

Демо-аккаунты (пароль у всех `password`):

| Роль  | Email                        |
|-------|------------------------------|
| Админ | admin@luckyten.test          |
| Игрок | player@luckyten.test         |

Пересоздать базу с демо-данными: `php artisan migrate:fresh --seed`.

При первом заходе (и после 10+ минут бездействия) показывается брендовая заставка: `resources/views/partials/splash*.blade.php`, логика в `resources/js/lib/splash.js`.

## Цены билетов

- По умолчанию билет стоит €0.10 (`TICKET_PRICE_CENTS=10`), пул билетов = стоимость приза × 10 ÷ цена (`TICKET_VALUE_MULTIPLIER=10`). Приз за €100 → 10 000 билетов, Porsche за €165 000 → 16,5 млн билетов.
- В админке при создании розыгрыша количество билетов считается автоматически, его можно переопределить вручную.
- Номера раздаются случайной выборкой с проверкой в базе пачками, поэтому розыгрыши на десятки миллионов билетов не грузят память.
- На странице приза кнопки быстрого выбора считаются от цены: €1, €2.50, €5, €10, €25 (при €0.10 это 10, 25, 50, 100, 250 билетов).

## Профили игроков

- У каждого игрока есть страница `/players/{public_id}`: участия, количество билетов, выигрыши (розыгрыши и instant wins).
- Профиль публичный только по согласию игрока: галочка при регистрации и переключатель в профиле. Показываются только имя, первая буква фамилии и город. Email, телефон, адрес, дата рождения и суммы никогда не показываются.
- Имена в ленте «Just won», у победителей и в блоке «Latest entries» на странице приза — ссылки на профиль, если он открыт.
- Лента «Latest entries» строится только из реальных оплаченных заказов.

## Instant Win

- В каждом розыгрыше можно спрятать мгновенные призы: деньги или вещи (админка → розыгрыш → «Instant wins»: название, тип, сумма, количество).
- Каждый приз привязывается к случайному ещё не выданному номеру билета (`App\Services\InstantWinService`). Игроки эти номера не видят.
- Когда при покупке (или при выдаче бесплатного билета) выпадает такой номер, приз сразу засчитывается: игрок видит анимацию выигрыша на странице заказа, приз появляется в кабинете, а на странице розыгрыша видно, сколько призов осталось и кто выиграл.
- Админка → «Instant wins»: список выигрышей с контактами и адресом победителя и статусом выплаты (To pay out / Paid / Shipped).
- Билет с instant-выигрышем всё равно участвует в главном розыгрыше.

## Логика билетов

- У каждого розыгрыша фиксированное максимальное количество билетов (включая бесплатные) и лимит на человека.
- Номера билетов уникальны внутри розыгрыша и выдаются случайно (`app/Services/TicketAllocator.php`), выдача идёт в транзакции с блокировкой строки розыгрыша — перепродажи не будет.
- Когда все билеты проданы, розыгрыш закрывается. Команда `raffles:auto-draw` (в планировщике каждую минуту) закрывает розыгрыши с прошедшей датой и проводит розыгрыш. Для продакшена добавьте cron: `* * * * * php artisan schedule:run`.

## Оплата

Сейчас стоит заглушка `App\Services\Payments\StubGateway` — любая оплата проходит сразу. Чтобы подключить Stripe/Adyen и т.п., реализуйте интерфейс `PaymentGateway` и замените биндинг в `AppServiceProvider`.

## Кабинет игрока

- **Кошелёк** (`/account/wallet`): денежные instant wins и реферальные бонусы зачисляются сразу; оплата билетов с баланса; вывод на IBAN (мин. €10), админ отмечает выплату или отклоняет с возвратом (`/admin/withdrawals`).
- **Пригласи друга** (`/account/referrals`, ссылка `/r/КОД`): оба получают `REFERRAL_BONUS_CENTS`, когда друг потратил `REFERRAL_MIN_SPEND_CENTS`.
- **Safer play** (`/account/safer-play`): лимит трат день/неделя/месяц (ослабление через 24 ч), reality check, перерыв от 24 ч до 5 лет.
- **Уведомления**: колокольчик, `/account/notifications`, любимые категории, напоминание за 24 ч до розыгрыша, браузерные push.
- **Мои данные** (Profile → Your data): выгрузка JSON и закрытие аккаунта (анонимизация, билеты и инвойсы остаются).
- **Инвойсы**: номер `LT-2026-000001`, PDF (монохромный логотип) прикладывается к письму и скачивается из заказа; «Купить снова» в заказе.

## Розыгрыш (provably fair)

При создании конкурса генерируется секретный seed, публикуется его SHA-256. В момент розыгрыша все билеты сортируются по номеру, победитель = позиция `HMAC-SHA256(seed, "id:кол-во") mod кол-во`. После розыгрыша seed раскрывается на `/raffles/{slug}/live`, там же проверка прямо в браузере и список всех номеров. Розыгрыш запускается сам по расписанию — нужен cron:

```
* * * * * cd /path/to/project && php artisan schedule:run >> /dev/null 2>&1
```

(`raffles:auto-draw` каждую минуту, `raffles:remind` каждые 15 минут.)

## Промокоды и flash sale

Админка → Promo codes (процент или фикс, мин. сумма, лимиты, даты). В форме конкурса — блок Flash sale: цена со скидкой до указанного времени, на карточках зачёркнутая цена.

## Push и PWA

`php artisan push:vapid` → вставьте ключи в `.env` (`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`). Сайт устанавливается как приложение (manifest + service worker, offline-страница). Push работает только по HTTPS (или на localhost).
